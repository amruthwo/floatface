Onewheel handshake capture

For Floatface, a Garmin watch app that talks directly to your board.

What you'll need

  • A Makerdiary nRF52840-MDK USB Dongle running Nordic's nRF Sniffer for Bluetooth LE firmware. Using a different nRF52840 dongle or a Flipper Zero? The main README's manual instructions still work for you -- this tool is built around the Makerdiary dongle specifically.
  • Your phone, with the official Onewheel app installed and able to connect to your board.
  • Chrome, Edge, or another Chromium-based browser on a laptop or desktop. Not Firefox or Safari -- they don't support the Web Serial/File System Access APIs this tool depends on, and there's no workaround for that. Brave works for Capture, but disables the File System Access API by default, so the Flash step won't work there (confirmed on Brave 1.92) -- use Chrome/Edge/Chromium if you need Flash too.

Nothing you do here leaves your computer. The dongle talks to your laptop over USB, everything is decoded locally in your browser, and the only output is a small text file you save yourself. No server, no account, no upload.

Flash your dongle

If your dongle is already running the nRF Sniffer firmware (for example, if you set it up previously), skip this step -- nothing here is required twice.

👇Hold the dongle's button down
→
🔌Plug it in, then let go
→
💾A "UF2BOOT" drive appears

This puts the dongle into its bootloader -- a tiny built-in program (separate from the sniffer firmware) whose only job is accepting new firmware. To your computer, that bootloader looks exactly like a USB flash drive named UF2BOOT; that's normal, not a different mode. Copying the firmware file onto it is a real flash, not just a file copy that sits there -- the bootloader watches for the new file, programs it directly into the chip, and reboots into it automatically.

This is Nordic's official nRF Sniffer for Bluetooth LE firmware (v4.1.1), pre-packaged for the Makerdiary nRF52840-MDK dongle -- see firmware/NOTICE.md for exact provenance and license.

Advanced: use a different .uf2 file (other dongles)

This only works for boards with a UF2 bootloader like this one (the "shows up as a USB drive" style). A genuine Nordic dev kit using Nordic's own DFU bootloader (e.g. a PCA10059) needs different tooling entirely -- see the main README's manual instructions for that path.

Need firmware for a different UF2-bootloader nRF52840 board? Get it from Nordic directly: nRF Sniffer for Bluetooth LE (you'll need to convert their .hex to .uf2 yourself -- see the main README).

Capture the handshake

📴 Laptop Bluetooth off
🔁 Board power-cycled
📏 Board, phone & dongle all nearby
🖱️Your browser will ask you to pick a device
→
✅Choose "nRF Sniffer for Bluetooth LE"
→
📱Then open the Onewheel app on your phone
👋
Ready when you are.
Tap "Start capture" whenever you're set.

Taking a while? BLE connections are sometimes flaky -- that's normal, not a bug. A few things that have helped:

  • Toggle your phone's Bluetooth off and back on, then reconnect the Onewheel app.
  • Double-check your laptop's own Bluetooth is really off.
  • Power-cycle the board again and retry.
  • Keep the dongle within a few feet of your phone and board.
