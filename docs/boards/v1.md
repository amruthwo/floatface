# Onewheel (original / V1)

**Status: essentially unknown.** The very first Onewheel. We have no
board-specific data for it -- placeholder page only.

## Identity

- Firmware generation: likely `1` in the release-order pattern (see the

- Tire diameter: unknown.

## Riding modes

Unknown. This board predates the Bay/Roam/Flow-style named mode system
entirely as far as we know -- may not even have multiple switchable modes
over BLE the way later boards do. Unconfirmed either way.

## Unlock scheme

Unknown. Oldest firmware of any board in this lineup, so if the
BLE-handshake scheme existed on it at all, it's the most likely candidate
for the local MD5 scheme working with zero per-board capture -- pure
speculation based on age, not evidence.
